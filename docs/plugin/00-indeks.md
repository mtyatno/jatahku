# Plugin dan ruang usaha Jatahku — indeks

Sistem **Fitur Tambahan** (plugin) untuk Jatahku, dengan **Buku Usaha** sebagai plugin pertama (ADR-P7). Uang usaha dipisah dari uang keluarga lewat **ruang**: ruang usaha adalah household kedua bertipe `usaha`, dengan banyak anggota, peran, dan batasan dari admin (ADR-P1, P4). Kartu Beranda menjadi registry dengan data batch, supaya plugin bisa menyumbang kartu. Chat (Telegram dan chat web) tetap hanya untuk ruang keluarga (ADR-P2).

**Fase sekarang:** Fase 1 (Beranda registry) selesai 1 Nov 2026: B1 #162, B2 #165, B3 #167/#168 (Gerbang B lulus, paritas produksi 105 user, p95 231 ms; flag `beranda_registry_users` dinyalakan bertahap oleh pemilik). Fase 2 (ruang usaha) selesai 5 Nov (R1–R8): R1 #161, R2 #166, dan R3 #171 tayang; R4 menambah `GET`/`POST /ruang` dan pemilih ruang di balik flag `ruang_usaha_users`. Ruang ditentukan `app/services/ruang.py`: membaca dari `ruang_aktif` (header `X-Jatahku-Ruang`, tanpa header = ruang keluarga); sejak R3 (#143) menulis dari objek yang ditulis, objek baru tanpa induk dari header, dan kuota Basic hanya di ruang keluarga; bot dan job selalu ruang keluarga. R4 tayang (#174). R5 (#145) menambah peran, batasan, dan antrean persetujuan: karyawan (peran `member` di ruang usaha) memakai tolak-bawaan, hanya route pencatatan dalam batasan dan jam kerjanya; di atas batas nominal catatan menjadi draf yang disetujui admin. Fase 3 (host plugin) dimulai: H1 (#176, tayang 4 Nov) menambah manifest, pemuat, validator CI, status plugin per ruang (pasang, lanjut, jeda, copot, pulihkan, arsip 90 hari), audit, dan saklar darurat; belum ada plugin terdaftar sampai U1. R8 (prive dua sisi, `POST /prive`, #177) dan R6 (#185) tayang 4 Nov; **Gerbang R lulus** (produksi `ruang_paritas` 109/109). R6 menambah halaman Anggota (`/ruang`: anggota, batasan tersimpan otomatis, undangan, antrean persetujuan, log, nama ruang), Beranda template "Karyawan" (registry menyaring kartu per peran: `untuk` umum/karyawan), menu dan Catat per peran, dan gabung ruang dengan kode. H2 (#186) selesai, review keamanan lulus: `PluginContext` (`app/plugins/sdk/`) dan titik ekstensi server (`app/plugins/host/titik.py`: kartu, cek, aturan advisor, perintah bot, notifikasi, job, kamus, field form). R7 (#191, tayang 5 Nov) menambah Catat cepat di ruang usaha dan kamus per ruang (`ruang_kamus`): urutan cocok kata user → kamus ruang → kamus Fitur Tambahan (H2) → kamus kategori, sumber tebakan, aturan admin untuk nominal, tawaran "pengeluaran pribadi" lewat permintaan terpisah ke ruang keluarga user sendiri, daftar/hapus kata di halaman Anggota, dan satu `client_ref` = satu catatan (409 `client_ref_bentrok`, review keamanan #191); lampiran foto nota karyawan ditunda ke sesi sendiri. H3 (#192, host di web): `GET /plugins/contributions`, persetujuan izin terikat layar izin (409 `izin_berubah`), kartu plugin di `GET /dashboard/cards`; di web grup menu Usaha, aksi plugin di menu Catat dan FAB, item "Lainnya" di HP, rute `/p/<id>` lazy, kartu plugin (deklaratif atau `src/plugins/<id>/cards.js`), dan halaman Fitur Tambahan (`/fitur-tambahan`). Tanpa plugin terdaftar tampilan semua user tidak berubah. **Fase 4 berjalan:** U1 (#196, tayang 6 Nov, **Gerbang H lulus 9 Nov**) menambah plugin pertama `buku_usaha` (manifest, kode server, modul web), empat tabel `p_buku_usaha_*` (migrasi `u1b0k0u5aha1`), endpoint plugin `/p/<id>/…` (`@plugin.rute`, `ctx.data()` untuk tabel plugin sendiri), wizard pasang 5 amplop bawaan, tab Kontak, ekspor data plugin (JSON/CSV) di panel dan layar copot, pembersih arsip yang menghapus data `p_*`, dan hook hapus akun/ruang; Buku Usaha hanya terlihat oleh user di flag `plugin_buku_usaha_users`. Berikutnya U2 (penjualan dan alokasi omzet). Status per sesi: `PROGRESS.md`.

## Aturan singkat

Sembilan aturan ada di `AGENTS.md` bagian "Plugin dan ruang". Yang paling penting: **ruang ditentukan server, tidak pernah oleh klien** (membaca lewat `ruang_aktif`, menulis dari objek yang ditulis) dan **chat selalu ruang keluarga**. Aturan "Aplikasi mobile" tetap berlaku, terutama **API hanya bertambah**, karena aplikasi Android dan iOS memakai bundle yang sama. Temuan keamanan dikerjakan sebelum fitur dilanjutkan.
